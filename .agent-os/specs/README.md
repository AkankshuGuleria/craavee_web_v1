# Specs index

This directory intentionally holds only short pointers — the canonical,
detailed specification lives in `docs/engineering/`. See
`docs/engineering/ENGINEERING_SPECIFICATION.md` as the entry point; it
links to every other document in that folder for its specific concern.

Each subdirectory here corresponds to one concern area from the Phase 1
engineering specification prompt and points to where that concern is
actually specified, to avoid maintaining the same content in two places.
